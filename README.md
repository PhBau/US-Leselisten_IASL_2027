# US-Leselisten_IASL_2027
The repository contains all data for the analysis of German-language university reading lists at North-American German language faculties.
The dataset is based on https://github.com/JanaEckardt/Leselisten_IASL_2025, revised and supplemented by 13 German language reading lists.
